# Translation prompts

This directory is the single source of truth for every built-in instruction
sent to a translation LLM. Templates are read from disk for every request, so edits take
effect on the next translation without changing Python code.

## Prompt sets

| Files | Used for |
| --- | --- |
| `subtitle_translation.system.md` | Direct subtitle translation |
| `ocr_translation.system.md` | OCR Translator captures |
| `subtitle_refinement.system.md` | Subtitle rewrite/refinement |
| `dubbing_rewrite.system.md` | Timing-aware dubbing rewrite |
| `subtitle_optimization.instruction.md` | Optional subtitle optimization pass |
| `dubbing_timing.instruction.md` | Retry prompt for an overlong TTS segment |
| `dubbing_initial.instruction.md` | Initial short dubbing translation |
| `rewrite_style_presets.json` | Rewrite style presets shown in the editor |

Files ending in `.system.md` become the system message. Numbered source items
are dynamic request data and are built directly by `prompt_builder.py`.

## Template variables

- `{{source_lang}}`: source language code.
- `{{target_lang}}`: target language code.
- `{{style_clause}}`: optional user style instruction, including its label.
- `{{action}}`: the current dubbing retry action.

The response parser requires exactly one `N. text` result for each numbered
input item generated by the builder.
